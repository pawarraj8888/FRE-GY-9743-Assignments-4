The model holds one piecewise-constant instantaneous forward rate (IFR) curve per component. A component's own discount factor is Dlocal(t) = exp(−∫0t f(s) ds), and the model follows the registered reference chain, so the funding curve SOFR-1B-FLAT returns DSOFR(t) · Dlocal(t). Curve time is ACT/ACT (ISDA) from the value date; tenors roll Following on the USGS calendar.
